## 레벨 순회 (Level-order Traversal, BFS)

### 개념
- 이진 트리를 **위에서 아래로, 같은 레벨에서는 왼쪽 → 오른쪽** 순서로 방문
- 너비 우선 탐색(BFS)을 트리에 적용한 형태
- 재귀로 구현되는 다른 순회(inorder/preorder/postorder)와 달리 **큐(Queue)로 구현**

### 동작 원리
1. 루트를 큐에 넣는다 (`offer`)
2. 큐가 빌 때까지 반복:
   - 큐에서 하나 꺼내(`poll`) 방문
   - 그 노드의 **왼쪽 자식 → 오른쪽 자식** 순으로 큐에 넣는다
- 먼저 들어간 노드가 먼저 나오는 **FIFO** 성질 덕분에 레벨 순서가 유지됨

### 시간 복잡도

| 항목 | 복잡도 |
|------|--------|
| 시간 | O(n) |
| 공간 | O(n) |

- **시간**: 모든 노드를 정확히 한 번씩 방문
- **공간**: 최악의 경우 한 레벨의 노드가 모두 큐에 들어감 (가장 넓은 레벨 = 최대 n/2개)
